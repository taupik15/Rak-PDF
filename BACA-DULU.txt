RAK PDF — UPDATE INTEGRASI BACA & SINKRONISASI

Pasang pada repo GitHub Pages khusus Rak PDF (root branch main).
1. Ekstrak semua isi ZIP, termasuk folder tersembunyi .github dan .nojekyll.
   Ganti file versi lama; pertahankan struktur data/ dan vendor/.
2. Commit dan push ke main. Di Settings > Pages, pilih Source: GitHub Actions
   (bukan Deploy from a branch). Workflow Rak PDF - sync and deploy akan
   menerbitkan web. Untuk repo dengan situs lain, jangan pakai workflow ini
   tanpa menyesuaikan folder publikasi karena workflow menerbitkan Rak PDF
   sebagai keseluruhan situs Pages.
3. Di Actions > Rak PDF - sync and deploy > Run workflow, gunakan main.
   Limit default 40 halaman per eksekusi; maksimal 150. Workflow juga
   berjalan setiap hari dan saat perubahan file aplikasi di-push.
   Jika pengaturan repo melarang bot menulis main, berikan izin yang sesuai
   atau tinjau proteksi branch. Jangan menonaktifkan proteksi tanpa alasan.
4. Lihat log Refresh public links. Buku Untuk Suamiku diprioritaskan pada
   sinkronisasi pertama. Setelah deploy, muat ulang halaman web.

Cara kerja
- Katalog awal tetap berisi 4.178 judul dari 19 November 2026. Belum ada URL
  baca atau PDF yang terverifikasi di dalam snapshot awal tersebut.
- Workflow memeriksa link buku terbaru di beranda (kategori yang dikenali)
  serta tautan PDF/reader publik dari halaman detail. Jika tombol Baca
  memakai JavaScript, browser mencoba klik normal pada tombol publik itu.
  Tidak menggunakan akun, token rahasia, proxy CORS atau menyalin file PDF.
- Sinkronisasi bertahap, bukan seluruh katalog sekaligus. Tautan lama tetap
  disimpan jika sumber gagal diakses; situs dapat mengubah atau mencabut URL.
  Tidak menjamin semua buku terdeteksi, terutama yang memerlukan login,
  URL sementara, domain eksternal, atau memakai mekanisme reader lain.
- Jika URL PDF tersedia dan CORS mengizinkan, buku dibaca langsung lewat
  PDF.js. Halaman terakhir tersimpan lokal. Jika reader publik tersedia,
  reader ditampilkan dalam iframe. Bila PDF gagal dimuat, tombol fallback
  menawarkan penyematan. Untuk URL belum sinkron, pengguna dapat mencoba
  menampilkan halaman detail di iframe dan menekan Baca di sana.
- Situs sumber dapat menolak iframe (CSP/X-Frame-Options) maupun CORS.
  Jika demikian, gunakan halaman resmi atau PDF yang diperoleh secara sah
  dan dibuka dari HP. Tidak ada jaminan iframe/PDF lintas origin pada Safari.
- Katalog situs lain tetap mendukung link PDF langsung dan feed OPDS/JSON
  dengan CORS. Contoh JSON: {"name":"Katalog","books":[{"title":"Judul",
  "pdf":"https://contoh.id/file.pdf","categories":["Umum"]}]}.
- Mesin PDF.js 5.4.624, Apache-2.0. Lisensi di vendor/LICENSE.

Validasi paket
- 3 tes Python resolver dan pemeriksaan sintaks JS lulus.

  Tautan aktual tombol Baca dan eksekusi workflow GitHub belum tervalidasi.
